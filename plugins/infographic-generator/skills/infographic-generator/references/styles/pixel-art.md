# pixel-art

Estética retrô de jogos de 8 bits

## Paleta de cores

- Principal: Paleta limitada - cores de NES/SNES
- Fundo: Preto ou azul-escuro, linhas de varredura (scanlines) opcionais
- Destaques: Realces de pixel brilhantes, brilho de tela CRT

## Elementos visuais

- Grade de pixels visível
- Quantidade limitada de cores por sprite
- Estilo de 8 ou 16 bits
- Elementos de interface de jogos retrô
- Bordas perfeitas em pixels
- Dithering (pontilhado) para criar degradês

## Tipografia

- Fontes pixeladas
- Letras quadradas e em blocos
- Texto no estilo de interface de jogo
- Estilo de exibição de pontuação e atributos
